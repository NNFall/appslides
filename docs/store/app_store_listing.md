# App Store Listing Draft

## App Identity

- App name: `Slide AI`
- Bundle ID: `com.appslides.slideai`
- Primary language: English
- Category: Productivity or Education
- Age rating target: 4+

## Short Description

Create PowerPoint and PDF presentations from a simple chat.

## Full Description

Slide AI helps you create ready-to-edit presentations in minutes. Type a topic, choose the number of slides, review the outline, pick a design, and receive editable PPTX and PDF files.

The app works like a chat assistant: all steps, buttons, files, and status updates stay in one conversation. Your chat history and downloaded files are stored locally on your device.

Key features:

- AI-generated presentation outlines.
- Editable PPTX export.
- PDF export for viewing and sharing.
- Multiple presentation design templates.
- PDF, DOCX, and PPTX conversion tools.
- Local chat history and local file access.
- Store-managed subscriptions.

## Subscription Products

Use the same product IDs in App Store Connect:

- `slide_ai_week`: Weekly subscription, 10 generations.
- `slide_ai_month`: Monthly subscription, 50 generations.

Display copy:

- Weekly: `Weekly — 10 generations`
- Monthly: `Monthly — 50 generations`

## Review Notes Draft

Slide AI is an AI presentation generator. The user enters a presentation topic, chooses slide count and design, then receives PPTX/PDF files generated by the backend.

Subscriptions are processed through Apple In-App Purchase in the iOS build. The backend validates App Store purchases through App Store Server API endpoints. Generated files are stored locally in the app-specific device storage.

Test account is not required because the app does not use account registration. Access is tied to a locally generated client ID.

## Required Before Submission

- HTTPS backend URL for iOS production/TestFlight.
- App Store Connect app record.
- App Store subscriptions with IDs `slide_ai_week` and `slide_ai_month`.
- Privacy policy URL.
- Support URL.
- Screenshots for required iPhone sizes.

- App Store Server API key configured on backend.

## CI/TestFlight Notes

Use the root `codemagic.yaml` workflow `ios-testflight-scaffold` as the first macOS CI scaffold. Codemagic must contain encrypted placeholder groups named `codemagic_app_store_connect` and `codemagic_ios_signing`; real Apple keys, certificates, and profiles must stay outside Git.

The scaffold builds the iOS App Store flavor with:

```bash
flutter build ipa --release \
  --build-number="$BUILD_NUMBER" \
  --dart-define=APPSLIDES_BILLING_PROVIDER=app_store \
  --dart-define=APPSLIDES_APP_STORE_WEEK_PRODUCT_ID=slide_ai_week \
  --dart-define=APPSLIDES_APP_STORE_MONTH_PRODUCT_ID=slide_ai_month
```

Keep App Store/TestFlight submission disabled until metadata, privacy URLs, screenshots, subscriptions, signing, and backend HTTPS readiness are checked in App Store Connect.
