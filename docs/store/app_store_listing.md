# App Store Listing Draft

## App Identity

- App name: `Slide AI`
- Bundle ID: `com.appslides.slideai`
- Primary language: English
- Category: Productivity or Education
- Age rating target: 4+

## Short Description

Create PowerPoint and PDF presentations from a simple chat.

## Full Description

Slide AI helps you create ready-to-edit presentations in minutes. Type a topic, choose the number of slides, review the outline, pick a design, and receive editable PPTX and PDF files.

The app works like a chat assistant: all steps, buttons, files, and status updates stay in one conversation. Your chat history and downloaded files are stored locally on your device.

Key features:

- AI-generated presentation outlines.
- Editable PPTX export.
- PDF export for viewing and sharing.
- Multiple presentation design templates.
- PDF, DOCX, and PPTX conversion tools.
- Local chat history and local file access.
- Store-managed subscriptions.

## Review Notes Draft

Slide AI is an AI presentation generator. The user enters a presentation topic, chooses slide count and design, then receives PPTX/PDF files generated by the backend.

Subscriptions are processed through Apple In-App Purchase in the iOS build. The backend validates App Store purchases through App Store Server API endpoints. Generated files are stored locally in the app-specific device storage.

Test account is not required because the app does not use account registration. Access is tied to a locally generated client ID.
